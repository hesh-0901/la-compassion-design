# LA COMPASSION DESIGN

Application d'inscription à la Masterclass Design du département Design de l'Église de la Compassion, Lubumbashi.

## Stack
- React
- TypeScript
- Vite
- CSS responsive

## Développement
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
```

Le dossier de sortie est `dist`, prêt pour Cloudflare Pages.
